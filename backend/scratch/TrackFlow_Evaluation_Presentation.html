🚀 TrackFlow: The Problem & SRS

The Problem (Manual)

  • Manual phone calls for order confirmation.
  • High RTO (Return to Origin) costs.
  • Slow, human-error prone tracking.

The SE Solution (TrackFlow)

  • Automated Shopify-to-WhatsApp Flow.
  • 3-Tier Architecture for scalability.
  • 24/7 Automated Parcel Polling.
Script (1 Min): "Sir, instead of just defining an SRS, we identified a real-world problem: Logistics loss. Our system, TrackFlow, applies SE principles to automate confirmation and tracking. Our Mini-SRS focused on two main actors: the Vendor and the Customer."

🏗️ Architecture & Component Logic

3-Tier Structure (High Cohesion)

📁 backend
  📁 routes (Presentation/Entry)
  📁 services (Business Logic)
  📁 prisma (Data Access Layer)

Design Decision: Low Coupling

We separated the WhatsApp Service from the Shopify Logic. This means if Meta changes their API, we only update one file without touching the Shopify flow.

Script (1.5 Min): "Look at our folder structure. This is not just random code; it is 3-Tier Architecture. We used Prisma as our Data Access Layer and separate Services for Logic. This gives us **High Cohesion**—each file has one job—and **Low Coupling**—modules don't rely on each other's internals."

📊 Transition: Business Rules to DB

Business Rule

"An order is only shipping-ready if the customer says YES."

DB Implementation (Crow's Foot)

Table: ShopifyOrder

Field: confirmationStatus (Enum: PENDING, CONFIRMED, CANCELLED)

Script (1.5 Min): "Our database design is driven by Business Rules. We used Crow's Foot notation to map a 1-to-Many relationship between a User and their Orders. We also implemented an Enum for status to ensure data integrity, meaning no 'garbage' status can enter the system."

🔒 Requirements Validation (Security)

The Threat

Anyone could send a fake POST request to our server pretending to be Shopify.

The Solution (HMAC)

We implemented HMAC Signature Validation. We hash the incoming data with a secret key. If the hash doesn't match, we reject it.

Script (1 Min): "In SE, Requirements Validation is key. We didn't just assume Shopify is safe. We validated the requirement of 'Security' by implementing HMAC SHA256 signatures for every incoming order. This is the difference between random coding and Software Engineering."

User Experience (UX)
