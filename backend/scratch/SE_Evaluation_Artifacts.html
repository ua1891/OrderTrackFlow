4. Architecture & Diagram Descriptions

A. 3-Tier Architecture Description

Tier 1: Presentation - React Dashboard (Frontend) for the vendor to view analytics.

Tier 2: Business Logic - Node.js Services (WhatsApp, Email, Poller) handling the core rules.

Tier 3: Data Layer - PostgreSQL Database via Prisma ORM for persistent storage.

B. Sequence Diagram Flow

1. Shopify sends POST Webhook -> Backend (Webhook Handler).

2. Backend validates HMAC -> Database (Save Order).

3. Backend calls Meta API -> WhatsApp (Message Sent).

4. Customer replies "Yes" -> Meta Webhook -> Backend.

5. Backend updates Database -> Sends Email to Vendor.
